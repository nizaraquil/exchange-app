# Money Exchange App

## Overview

The **Money Exchange App** is a simple web application that allows users to convert currency amounts from one currency to another. It utilizes the Fixer API for currency conversion and provides a user-friendly interface for the task.

## Features

- **Currency Conversion:** Easily convert currency from one type to another, whether it's dollars to euros or any other pair of currencies.

- **User-Friendly Interface:** The app provides a user-friendly and intuitive interface, making it simple for users to input their desired amount and select both the source and target currencies.

- **Conversion Result:** Get real-time conversion results, including the date, ensuring you always have the latest exchange rate information at your fingertips.

## Installing Libraries

To run the Money Exchange App on your local machine, you need to install the required libraries. You can do this using `pip` and the provided `requirements.txt` file. Here's how to do it:

1. Open your terminal.

2. Navigate to the directory where you have the Money Exchange App files.

3. Run the following command to install the necessary libraries:

   ```bash
   pip install -r requirements.txt
